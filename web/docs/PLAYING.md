# 上桌指南

## 一键复原手牌

手牌右下角的「复原」会把散牌按大小重新排列，清除当前选牌，保留你手动建立的成组；可以用「理牌 → 撤销」或 Ctrl+Z 撤销。理牌菜单仍提供花色、牌型排序和拆开全部成组。四家明牌练习中的「复原」则恢复建议牌型分组，不撤回已出的牌。

## 操作区域与小窗口

同花顺、成组和玩家状态按实际宽度排列，允许换行；选牌状态栏为右侧操作区留出空间。电脑窗口较矮时，操作按钮缩小但不低于 48 像素，空间不足时使用两列。手机手牌减少时仍保留操作列的高度。窗口高度低于 700 像素时，牌桌改为可滚动布局，Top 5 内嵌显示，按钮使用自然排列。手牌工具单独占行；手牌出完后隐藏无用途的理牌工具。

局末的「下一局／再来一场」与战况入口放在结果卡内，结果显示期间评价与手牌工具暂时隐藏。明牌练习继续使用自己的固定操作网格。

## 页面内也有帮助

第一次上桌，可以点大厅底部“查看玩法与操作”，或对局右上角“帮助”。“打牌规则”会显示本桌选定的进贡与打 A 规则；“操作方法”介绍扫选、拖动、成组、理牌和快捷键。

帮助支持手机横竖屏、键盘切换标签与 Esc 关闭。单人查看时暂停计时与电脑落牌；朋友房间继续计时。明牌练习中的点击不会穿透帮助去推进下一步。

## 开始一桌

单人练习和朋友入座的操作见下文；「训练」与「观战」是独立入口。

## 观战朋友的牌桌

在大厅点「观战」，输入房主的四位房间号，再点「进入观战」。最多六位观众，不占四个玩家座位，房主尚未开局时会显示等待，开局后自动显示牌桌。视角以房主为底部，四个座位用编号和昵称标识。

观众只接收公开出牌、剩余张数、级牌和级数，不接收洗牌种子、牌堆或其他人的私牌；不能出牌、选座、触发评价或恢复玩家凭证，也不把观战动作记为真人训练样本。它与单机四家明牌训练、房主的独立明牌工具是不同功能。

观战页可点「开麦／闭麦」交流。房主在牌桌「选项」里能查看房间号，并分别关闭／允许每位观众的语音；重新允许不会自动打开观众的麦克风。房间连接断开或房主离开后，观战结束，点「退出观战」回大厅。公开牌面约每秒刷新一次，观众不能接管房主退出后的牌局。电脑、平板和手机均支持自适应布局。

## 入座与开局

单人练习：输入昵称 → 选座位 → 坐下开始。其余三个座位由电脑接管。

朋友房间：房主开房并选座 → 复制邀请链接 → 朋友进入并选座 → 房主开始。也可以使用四位房间号加入。

房间里的对家是队友，左右两家是对手。页面以你自己的座位为底部，不需要按房主视角记座位。

大厅牌桌中央点「选级」，分别选择南北、东西的 2 到 A 级数，以及本局打谁的级。还可以填写上一局头游到末游的方位、各队打 A 失败 0／1／2 次，模拟接着之前的牌局打。名次必须四家完整且不重复才产生进贡关系；选完三家自动补齐第四家，弹窗会预览单进贡／双进贡。没有完整名次时不安排进贡；打级方选「自动」时，完整名次按头游队，否则按房主队。

加入者只能查看，房主统一设置。该续局设置仅应用于本桌第一次开局；打完整场再开时恢复从 2 开始，刷新恢复则继续当前局，不重新套用初始名次。点「还原」清空设置，Esc 或点遮罩可关闭。

每局打上一局获胜方的级：一方已到 A，但上一局是对方赢的，这一局打的是对方的级，即使拿到头游和二游也不算打过 A，只会让下一局改打本方的 A；在本方打 A 的那一局拿到头游、且队友不是末游，才赢下整场。结算面板会写明是“本局打的是对方的级”还是“队友是末游”。

「三次打 A 不过」可选平局、从 2 打或「一次机会」。一次机会模式中，某队三次未过 A 后失去本场冲 A 获胜资格；另一队轮到打 A 时只剩一次机会，成功获胜，失败则整场平局。牌桌以 A1、A2、A3 显示尝试次数，最后一次机会显示 A末。

## 一局的流程

洗牌与切牌 → 发牌 → 必要的进贡 → 理牌与还贡 → 出牌 → 结算与升级。

每局对完整的 108 张实体牌随机洗牌、每人发 27 张；六张及以上炸弹和四张王都可以自然出现，发牌不根据手牌强弱追加重洗。

轮到你洗牌、切牌或结束理牌时，相应按钮会出现。理牌结束后进入正常出牌；计时结束会自动推进相应阶段。

还贡通常选择 10 或以下的非百搭牌；没有符合条件的低牌时，归还最小的非百搭牌。页面会根据你的整手牌提示可还的范围，电脑与联机入口使用同一套判断。

## 理牌与出牌

| 操作             | 方法                                                 |
| ---------------- | ---------------------------------------------------- |
| 选择牌           | 点按；鼠标可扫选或拖动                               |
| 组成固定的一组   | 选择牌后点「成组」，或拖入成组区                     |
| 调整牌的位置     | 拖动到希望的位置                                     |
| 查看合法出法     | 点「提示」依次查看                                   |
| 找同花顺         | 点「同花顺」循环选择手里能组成的同花顺               |
| 换展示方式       | 在横式、竖式、手持之间切换                           |
| 按大小或花色排序 | 「理牌」里选择对应方式；手动成组保留                 |
| 智能理牌         | 「理牌 → 智能理牌」，将散牌按组合相邻排放            |
| 拆开全部成组     | 「理牌 → 拆开所有组」                                |
| 撤销理牌         | 「理牌 → 撤销上次理牌」，或 `Ctrl / ⌘ Z`             |
| 重做理牌         | 「理牌 → 重做理牌」，或 `Ctrl / ⌘ Shift Z`、`Ctrl Y` |
| 避免误触         | 在「选项」打开出牌确认                               |

合法性以你实际选中的牌为准。提示只给出可以出的组合，不代表唯一最优出法。

「同花顺」会提示总种数与当前第几种；遍历后再点一次放下选牌。固定成组的百搭炸弹跟普通牌型时，提示会保留整组炸弹出法。

手牌上方会显示所选张数、牌型与当前能否出牌；不成牌型、压不过或不符合进还贡要求时会解释原因。点「取消选择」或按 Esc 可以重新开始。

理牌撤销与重做最多保留 30 步，包括成组、放回与拖动。撤销后执行新的理牌操作会清空重做；自己的手牌发生变化后会清空历史，避免把已经打出的牌恢复回来。按花色和智能理牌会切到横式展示，以保留排好的先后顺序；之后仍可以自行换布局。

## 快捷键

在对局页面、没有输入昵称或编辑记录时：

- `H`：下一条出牌提示。
- `P`：提交选牌；进还贡时确认所选牌。
- 焦点在手牌上时：`←`／`→`、`Home`／`End` 浏览，`Space`／`Enter` 选牌。
- 焦点在手牌外时：`Enter` 提交选牌，`Space` 过牌。
- `Esc`：取消选择或正在进行的拖动。
- `Ctrl / ⌘ Z`：撤销上次理牌。
- `Ctrl / ⌘ Shift Z` 或 `Ctrl Y`：重做理牌。

先手不能过牌。选择不合法组合时，页面会保留操作并提示原因。

## 房间与声音

大厅底部展开「电脑模型」，只有四项：Clint规则机器人、最新一代 GuanZero、danMCai 现任冠军 danMCai-v000855042 和带推理的 danMCai-reason-v000855042。默认使用 danMCai-reason（冠军 017 加手牌推断搜索；只在无进贡单局对冠军验证过，对真人和进贡局未测）；「全部恢复默认」可重置，想用冠军 017 可单独选择。以前选过已退出菜单的初始版、上一任冠军或旧 GuanZero 的座位会自动改回默认。GuanZero 名称为 `训练任务名-版本数值`；具体版本见 [电脑选择](WEB_MODELS.md)。Clint 不使用神经网络，冠军指开发门控晋升，不代表独立验收或全局最强。朋友房间由房主设置，恢复时保留对应座位的电脑选择。

语音由你主动打开麦克风。首次点击或按键会唤醒浏览器音频，这是浏览器对自动播放的限制。

对局中点右下角「理牌」右边的圆形 😊 按钮，面板会在按钮正上方弹出，分「表情」「快捷语」两页，可以给同桌发表情或快捷语，**只能从预设里选，不能输入自由文字**。同一个人两次发送至少间隔 2.5 秒，冷却时按钮变灰并有一圈进度。复盘时不显示表情按钮。

- **送礼物**：卡布奇诺、鲜花、炸弹。点礼物后再选送给哪一家，礼物会从你的名字牌飞到对方名字牌：炸弹落地爆炸、对方座位震动；鲜花撒花瓣；卡布奇诺冒热气，各配一段音效。
- **表情**：墨镜（从上方戴上并闪光）、哭（摇晃流泪），显示在你自己的名字旁。
- **快捷语**：8 句纯寒暄，不含「别炸」「这一炸漂亮」这类会向队友传递出牌信息的话，例如「快点吧，我等的花儿都谢了」「给阿姨倒一杯卡布奇诺」。文字在名字旁弹出约 3.5 秒，同时由浏览器自带的中文朗读念出来，每个座位音调不同。这是浏览器合成语音，不是其他游戏的原版录音；声音跟随「音效」开关，浏览器没有中文语音时只显示文字。
- **电脑会回礼**：把礼物送给电脑座位（单人局或房主所在的房间都可以），电脑约 1–2 秒后回应：卡布奇诺和鲜花会回送同样的礼物或戴上墨镜，炸弹会炸回来或者哭。每个电脑约 6 秒内只回一次，只回应真人送的礼物。回礼只是表情，不影响电脑出牌。

不想看别人的表情时，打开表情面板底部的「屏蔽他人表情」开关（同时停止朗读），这个选择只保存在你自己的浏览器里。系统设置了「减少动态效果」时，礼物直接出现在对方名字牌上，不播放飞行和粒子动画。表情不算出牌动作，不进入出牌记录、牌谱、复盘或云端采集。

掉线后，该座位暂由电脑接管。原标签页会尝试重新连接，刷新后也可以恢复到房主当前局面。房主关闭页面时，其他玩家可以选择在本机与电脑继续。恢复条件与限制见 [房间指南](./ROOMS.md)。

## 手机上更舒服的方式

想研究一手牌时，可在大厅进入 [复盘练习](./PRACTICE.md)：四家明牌，逐步推进，带评语的记录可以导出后分享。普通朋友房间保持正常暗牌玩法。

页面会根据宽度与横竖屏重新排牌。可以尝试横屏和全屏；如果切回应用后没有声音，点击牌桌或声音按钮重新唤醒。

## 遇到问题

先确认大家的页面版本一致。连接失败时重新打开邀请链接；模型资源失败时使用重试入口。反馈问题时，附上设备、浏览器、页面版本和具体操作步骤，避免只写「不能玩」。

## 牌谱与整场战况

普通对局中打开 **选项 → 牌谱与战况**，可以切换本场已经结束的局，按玩家筛选公开出牌和过牌。筛选保留原来的手数，方便交流“第几手”。当前局随出牌更新；复制和“下载牌谱”保存所选局，“下载整场”保存本场所有保留记录及当前进度。

展开“整场战况”查看两队胜局、各座位的头游／出牌／过牌／炸弹次数和历局名次；结算页也能直接进入。统计包含本场已保存局和当前局的公开动作，过牌次数不表示手里没有能压过的牌。

查看期间对局计时继续。按 Esc 或“返回牌桌”关闭。记录最多保留最近 200 个已结束局和当前局，进入新的一场会清空；请提前下载需要保留的牌谱。加入者在原座位恢复时，会一起恢复本场记录；房主关闭页面后无法从静态网站恢复整桌。

导出的内容只有公开动作和已结算名次，不含未打出的手牌。需要四家明牌、评语和重打，请使用大厅的 [复盘练习](./PRACTICE.md)。

## 可选出牌评价

房主在开房页允许「出牌评价」后，玩家才能在牌桌「选项」中自行开启；新房间默认不允许。轮到本人时选牌预评，出牌后保留上一手，也可随时关闭。评价默认用 danMCai-reason：牌桌剩 40 张以内时显示它的推理搜索值（Top 5 上方注明「推理搜索」或「残局推理」，可能要等一两秒），其余时候用冠军估值。百分数是当前候选之间的相对分，不是胜率或正确概率，模型也可能误判。[完整说明](MOVE_COACH.md)。

出牌评价开启后，当前选牌显示相对合理性，推荐窗口给出最多五种实际用牌。点击推荐只是选牌，仍需点出牌／过。手机可收起 Top 5，选项里可关闭整项功能；分数不是胜率。详见 [评价指南](MOVE_COACH.md)。

## 显示与计时

桌面和平板的四家名字牌使用相同尺寸，两侧对称；对家余牌张数在名字右侧、计时旁显示（延续只在余牌不多时显示的规则）。洗牌、切牌动画集中在桌心，手机保持紧凑布局。出牌区不再叠加重复的牌型文字；「选项 → 牌背」增加「无」，不显示桌面牌背堆，旧迷你出牌开关已移除。

还贡倒计时为 60 秒，最后 10 秒催促提示。选用 Clint规则机器人的真人座位超时，跟牌直接过；领出按完整牌组、固定组合、炸弹和合法兜底处理。其他网络模型的超时托管仍使用所选网络，独立房主工具保留自己的处理路径。选 `danMCai-reason-v000855042` 的真人座位超时托管直接出冠军 017 的牌；该研究机器人坐电脑位时，桌上剩 40 张以内会多想一会儿（通常不到 1 秒，个别尾盘几秒，手机更慢）。电脑和真人一样每手最多 60 秒：推理最多到回合开始后 50 秒（电脑和手机相同，含思考停顿和首次加载），留 10 秒给回落，超过就改出冠军 017 的牌；Clint 电脑的残局大脑同样最多 30 秒且不超过 50 秒，超时出只用规则的出法。一手回落后，下一手照常推理。普通 Clint 电脑正常轮次的策略不受这个真人超时分支影响。

旋转平板或切换全屏后会按实际尺寸重排。需要排查设备问题时，可在网址末尾追加 `#debug` 查看尺寸；不会修改浏览器的 viewport 设置。当前自动验证使用 Chrome，不能代替 iPad Safari 真机验收。

## 图解规则书与本局显示

“第一次玩？”和“规则”打开四类分页规则书：新手入门、牌型一览、升级进贡、操作计时。牌面示例以打2为准，进贡／打A／计时按当前桌规显示；“更多操作”保留本项目键盘和房间说明。

“继续上一场”移到选级框内，仍保留匿名整场连续性及明牌排除位。局末左上角保持刚打完这一局的级数／A次数，到下一局才更新；另一方尚未轮到打A时保留上次尝试编号。收牌翻面期间可以选牌，但出牌按钮在真正轮到你后才亮，不排队自动提交。同一批实体牌的同花顺只显示一次，优先高顺，不列用百搭替换已有自然牌的重复提示。

### iPad入门

用Safari打开本站，横屏可显示更大的牌；旋转后会自动重排，也可通过“分享→添加到主屏幕”使用全屏入口。先填昵称、选座位，再单人开始或由房主开房邀请朋友；昵称在手机上也允许8字。首次声音或麦克风需要一次触摸／权限允许。房主尽量保持页面在前台，避免锁屏长时间中断；同一浏览器的同版本存档三小时内可恢复，明确退出会清除。不要把添加到主屏幕视为另一浏览器存档已自动转移。手持／横式／竖式、成组、提示与出牌确认见本页原操作章节；出牌评价是相对动作值，不是胜率。
