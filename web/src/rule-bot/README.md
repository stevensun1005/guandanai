# Clint规则机器人 · rules-v2

此目录只负责纯规则电脑，不参与网页神经网络的动作评分、候选动作生成或 Worker 推理，也不训练网络。

| 文件             | 职责                                               |
| ---------------- | -------------------------------------------------- |
| `settings.js`    | 规则参数与启用项                                   |
| `arrangement.js` | 规则对手专用拆组与百搭成本，独立缓存               |
| `strategy.js`    | 阶段判断、跟牌、保炸、让队友与公开信息推断         |
| `runtime.mjs`    | 网页规则 Worker 的私牌隔离、初始化和实体牌 ID 返回 |

`createRuleOpponent(seed)`（`ai/shared/simulation/rule-baseline.mjs`）使用此版本。接口只收到自己的实体手牌、其他玩家的剩余张数和公开牌史。根据过牌、进还贡和已出牌推测剩余分布属于统计抽样与规则推断，不是神经网络或在线学习。

`createRuleBaseline(seed)` 保留 `original`，供历史评测与现有训练复现；不要用新版对手的名称解释旧结果。整场模拟可显式传 `playMatch({ ..., ruleVersion: 'rules-v2' })`，默认仍为历史版本，避免无声改变训练对手池。

单把评测命令 `node ai/danMCai/evaluation/evaluate-trained.mjs --opponent=rule` 默认使用 `rules-v2`，输出记录 `ruleVersion` 及三份源码指纹。可加 `--rule-version=original` 复现旧对手。**该命令是单把评测，不能作为整场胜率证据。**

新版主要包括：按最后出牌者余牌划分阶段；保留唯一炸弹；不炸队友的三带二；只剩一炸与一手其他组合时优先走其他组合（保留对手余牌张数例外）；结合公开信息抽样估计接牌与队友需求。测试覆盖合法性和信息边界，不据此宣称更强。

## 真人超时分支

`timeout.js` 只服务选用 Clint 的真人超时：跟牌过牌；领出先选不拆散的散牌组合（单、对、三、三带二、顺子、三连对、钢板），再选固定的非炸组合，再按炸弹强度选择，最后合法兜底。完整牌组检查不把百搭散牌冒充自然牌组，固定分组只读取本人可用的分组；客人分组没有同步时不推测其手动意图。

`runtime.mjs` 的 `decideClintTimeout` 返回实体 ID，Worker 消息为 `rule-timeout`。普通 Clint 电脑继续使用 `strategy.js`；神经网络和独立房主工具不叠加此规则。该分支属于行为兼容性适配，没有新的独立胜率证据，旧规则对手成绩仍绑定原指纹。

## 公开牌史策略更新

同步范围 `7323a12…54fde9e`，仍属于 `rules-v2` 路线，但新旧对手必须靠源码 SHA 区分；历史比赛成绩不自动迁移。

- 跟单张时，优先走整理后不含百搭、点值不超过 A 的最小可压单张，可跟队友的单张。
- 对手单张能被非红心级牌压过且没有上述散单时，级牌先于大小王，必要时拆级牌对子。
- 领牌时，优先考虑队友曾领出、被对手接走且队友未再出牌的对子／三带二／顺子，最近的牌型优先、同型出小；保留更高优先级的收尾和余牌防守。
- 对手本局第一次出单张、队友尚未应牌、桌面不是小王且本人只能用大王跟单时，先给队友机会。公开进贡已表明队友没有小王时不适用；也不覆盖能直接走完的优先级。

这些是 Clint 启发式，不是神经网络、自我学习或实测胜率提升。只读本人手牌、公开出牌和公开贡牌；不修改 danMCai／GuanZero、original 基线、真人超时独立分支或冻结训练。方法、原始指纹与验证见[研究证据](../../../ai/research/evaluation/clint-sync-20261106-1404.json)。
