# 当前真人牌谱与029出牌选择的比较

这批样本中，人工操作更常在有合法应牌时过牌，更少继续压住队友、更少使用炸弹；029在相同观察下更常出多张组合。它们是行为差异，不证明哪种打法更能赢，也不构成训练奖励、战术规则或出牌推荐。

## 范围与数据质量

本次只读导出共用D1库至游标124，覆盖当前可导出的全部记录：124条均合法重放，109条`kind=game`、15条测试；没有重复ID或非法记录。正式记录属于12个整场会话，全部来自Clint网站，本项目本站在此快照中没有正式记录。最新一局在多伦多2026-11-14 22:14结束，最早在11月7日13:49开始。

109局中104局开局四席真人，5局三席真人。会话内有4处局号缺口，未证明整场完整；人类身份由浏览器自报，昵称不能认证身份，12个会话也不等于12名独立玩家。未上传、单人、未结束和明牌排除局不在本研究范围。

正式局共记录9125个人工动作、111个机器人动作和1个超时托管动作。人工动作中790个明确标记`assisted=true`，8335个没有辅助标记，明确`assisted=false`为0。主分析使用8335个未标记辅助动作，不能称为已确认的完全未辅助人类样本；790个标记辅助动作另列汇总，不作历史覆盖或标签纠正。

排除只有一种方案及模型自动收尾的1786个动作后，主分析有6549个可选决策机会，实际人工方案均在生成器的等价牌型/点数方案中。测试局、机器人和超时托管均不进入该分母。

## 比较方法

逐局复原真实历史，在每个人工动作提交前，向固定029原网络仅提供该席手牌、公开出牌、公开剩余张数及公开级数。模型一列是该相同局面下模型会选的牌，不是模型另打了109局，更不是其后续胜率。029使用完整SHA`4f5d8ef453f9627d73130ffccf320b49fff0a77dbed1bf390032a5e66f849768`；017参照SHA`462afc99ee6bcfb788871d7a8f84d4298c008d57465c62d48ca1792cdb11b3f7`。

沿用网页的自动收尾/唯一候选处理；比较时将相同牌型、点数及百搭使用方案分组，不要求两副相同实体牌ID相同。模型输入不包含其他三席的私牌、事后名次或最终结果。没有运行明牌求解、reason搜索、GuanZero推理、反事实续打、新模拟局或优化器更新。不能把029原网络结果转用于reason搜索。

各行均在同一批符合该条件的人工局面上比较，不合并不同条件的分母。

主动领出平均张数：人工2.7304，029为3.5357。炸弹类包含普通炸弹、同花顺和四王；统计描述使用倾向，不说明用得多或少哪个更好，也没有把“压队友”直接定义成错误。

029与人工选择相同等价方案2929/6549，44.72%；017为2866/6549，43.76%。一致率不是正确率，也不能用来给两模型排棋力。两模型在过牌、队友出牌和用炸上的差异方向一致。

按本人剩余手牌分层，029与人工的一致率为：20张及以上1319/2956=44.62%，10–19张1091/2627=41.53%，1–9张519/966=53.73%。这里是本人手牌张数，不能当作全桌剩余张数或精确的比赛阶段。

## 不确定性与解释界限

按整个记录会话重采样2000次，固定随机种子2026111507。区间只描述这12个记录会话中的变化，不保证会话间玩家独立或代表总体人类：

| 指标 | 样本内点估计 | 会话簇bootstrap 95%区间 |
| --- | ---: | ---: |
| 029与人工相同方案比例 | 44.72% | [42.76%, 47.58%] |
| 有应牌时过牌：人工减029 | +19.84个百分点 | [+17.69, +21.44]个百分点 |
| 队友最后出牌时继续出牌：人工减029 | −16.61个百分点 | [−19.54, −13.00]个百分点 |
| 有炸可用时用炸：人工减029 | −23.52个百分点 | [−25.93, −20.41]个百分点 |

这些差异不能回答真人是否更强、模型哪手浪费了炸弹，或者模仿人类是否提高胜率。104局四席真人局尤其不能产生“真人对AI胜率”。模型在真人访问到的局面上出牌的方式，与模型自己完整比赛的状态分布也不同。

值得进一步检验的假设是：模型在让队友继续出牌、资源使用与人类对手分布上，可能存在需要用终局收益验证的差异。应把这批牌谱作为外部诊断数据隔离保留，再用独立模拟数据做完整终局对照，判断哪些分歧实际影响本队结果；这些标签本身不进入奖励、损失或门控，也不自动将真人数据接入训练。
