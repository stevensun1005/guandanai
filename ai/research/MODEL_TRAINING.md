## 数据从哪里来

5,000 局固定种子自对弈，混合均衡、激进、稳健、观察四种教师风格。每次出牌后，如果下一位仍在场的玩家是对手，就记录其真实的出／过选择，得到 167,659 条样本。特征只取出牌者自己的牌、未公开牌的合计分布、公开记录、剩余张数、级牌与待选动作。

按**整局**切分：局号模 10 等于 0 是测试，等于 1 是验证，其余训练，共 4,000／500／500 局。同局的相邻动作不会分散到训练与测试两边。早停与网络选择使用验证集，测试集只作最终报告。

训练采用固定随机种子、NumPy Adam 和二元交叉熵，另训练一个线性预测基线。可复现脚本不启动网络服务，也不自动覆盖已发布权重。

```bash
python -m pip install -r ai/environment/requirements-models.txt
node ai/danMCai/data/tools/collect-responses.mjs --games=5000 --seed=20270104 --output=ai/danMCai/data/generated/dataset
python ai/danMCai/training/train_response.py ai/danMCai/data/generated/dataset ai/danMCai/data/generated/candidate
```

数据约 171 MB，放在忽略提交的 `ai/danMCai/workspace/`。编码版本、教师文件 SHA 和实际样本数会写入数据元信息。教师或规则变化后应重新采样、训练和评估，不要把旧测试成绩移到新权重上。

## 预测结果

测试集 500 局、16,769 条样本：

| 模型           |     Brier ↓ |       AUC ↑ |
| -------------- | ----------: | ----------: |
| 训练集常数概率 |     0.24860 |     0.50000 |
| 线性预测       |     0.16334 |     0.83832 |
| 应牌小网络     | **0.15321** | **0.85785** |

按整局重采样 2,000 次，应牌网络相对线性的 Brier 改善 0.01014，95% 区间 [0.00851, 0.01183]。NumPy 与导出 ONNX 的最大误差为 0.00000018；浏览器另用 24 个真实局面核对第二个模型和最终选择。

完整报告：[训练与校准](./evaluation/response-training-1.7.0.json) · [按局 Bootstrap](./evaluation/response-bootstrap-1.7.0.json)。这些成绩预测的是样本教师的行为，不是所有真人的概率，也不把过牌解释成不能出牌。

## 从预测到出牌

观察型先按原策略决定出牌还是过牌；融合型使用相同的受限预测路径，并按观察偏好的权重缩小影响。只有它已经决定出牌、下一家是对手、并且至少两种出法处于主策略最佳值 0.055 范围内时，才加载应牌模型作小幅排序。它不能把“过”改成“出”，也不能把“出”改成“过”；残局的已证明路线优先。

我们也试过直接把应牌概率加到出／过评分上，这种用法在留出对局中没有优势，因而没有发布。条件概率适用于比较已决定打出的牌，不足以单独决定是否该过。

最终用法在 3,000 组交换双方、共 6,000 局的留出种子 `20300104` 上检查，对手为未使用第二模型的观察型，双方均启用当时上限为 16 张的精确残局。胜率 50.23%；配对升级分均值 +0.02733，95% 区间 [-0.01208, 0.06674]。**区间包含零，尚不能宣称棋力提升。**默认均衡型保持不变。

```bash
node ai/danMCai/evaluation/evaluate-response.mjs --pairs=3000 --seed=20300104 --endgame-cards=16 --output=web/artifacts/validation/response
```

[对局结果](./evaluation/response-policy-1.7.0.json)。这是随机级牌的独立单局，不包括跨局进还贡与整场打 A。新模型进入默认策略前，仍需新的留出局、更多对手和设备验证。

## 扩展与发布

模型清单在 `web/src/ai/models.mjs`，构建自动复制资源并为每份权重计算内容版本。Worker 为不同模型维护独立推理会话；应牌模型只在需要时加载。普通玩家和加入者无需运行 Python。

新增权重应同步更新元信息、独立留出报告、编码检查与浏览器误差检查。不要仅改风格名称就声称增加了独立模型，也不要用一次漂亮选牌代替对局验证。

## 主网渐进训练（实验）

完整主网已完成后层、中后层、全层三个阶段的实验，使用整场团队结果和生成器提供的全部合法候选进行蒙特卡洛价值学习。后续另完成全候选 PPO 与公开／明牌评价、开局重打的四组对照；这是不同的方法，不应统称为同一次渐进解冻训练。训练专用明牌 Critic 不参与网页出牌。参数范围、复现入口和实际完成量见[训练记录](./TRAINING_RUN.md)，当前结论见[研究主报告](./MODEL_STUDY.md)。该批历史实验不决定当前网页默认；当前默认依据danMCai 实际门控冠军与发布清单。
