# 进还贡专项网络

独立的共享网络，供 danMCai 和 GuanZero 在进贡／还贡阶段使用各自输出头。它不修改两个主网络的权重，也不注入 Clint 策略。网页尚未启用；冻结的 Mac 和另一台电脑训练保持原样。

输入是本人手牌、合法候选、双方级数、上一局公开名次和已公开贡牌；不包含他人私牌。389 → 256 → 128 → 2，隐藏层 tanh，132,994 个可训练参数。全部层参与 Adam 更新，学习率 0.0003、batch 上限 1024、梯度裁剪 1；每轮拟合 20 epochs。

每个决策遍历不同牌面的合法贡／还选项，再用固定神经网络打完本局。标签是本队最终 ±1／±2／±3 升级分，按决策组居中；不是短期牌权、拆牌代价或手工战术分。每个动作目前只有一条确定性续打路线，存在教师偏差与隐藏牌采样方差。先前名次和级数是规则合法的合成场景，并非真的从上一局接续生成；不能据此声称整场打过 A 的能力提高。

## 固定窗口

本次明确截止为 **2026-11-06 08:00 America/Toronto（13:00 UTC）**。重启不续时。独立运行目录为忽略的 `ai/danMCai/runs/tribute-20261106/`，协议、原始反事实样本、优化器、最佳导出与状态都保留。禁止覆盖 baseline、旧主运行或另一台电脑的数据。

```powershell
node ai/shared/tribute/prepare.mjs --run=<绝对新运行目录> --finalize-root=<融合验证检出>
node ai/shared/tribute/run.mjs --run=<同一目录> --python=<具备 GPU 的 Python>
node ai/shared/tribute/dashboard.mjs --run=<同一目录> --port=8789
```

`prepare` 拒绝覆盖协议；必须先提交代码，再在独立冻结检出准备。运行核对规范化 LF 源码 SHA 和协议 SHA，检查点与数据都绑定协议。每十分钟拟合，首批数据足够时提前首训。单采样进程、单原生推理线程、低于正常优先级；可用内存低于 4 GiB 暂停采样／拟合。内存保留是轮询软预算，不能承诺操作系统瞬时峰值绝不越线。推理申请 DirectML，图中部分算子可能回退 CPU；专项梯度训练使用 ROCm PyTorch 的 `cuda:0`。

面板 `http://127.0.0.1:8789/` 每五秒读取真实落盘状态，显示训练／开发决策组、已完成整局回放、网络更新步数、可用内存、采样 CPU 和固定截止。训练失败、心跳陈旧与等待融合有不同状态，不展示计划局数为已完成。

种子区间：短测 3,799,000,000–3,799,999,999；训练 3,800,000,000–3,899,999,999；开发 3,900,000,000–3,999,999,999；独立留出前 128 个种子从 4,000,000,000 开始。留出不参与最佳导出选择。

## 融合与验收

共享专项模型是阶段适配器，不是把不同结构主网络的权重相加。到点先停采样和梯度，再用固定教师及独立种子交换阵营评测。每条路线计划 128 对完整单局，报告胜负、升级分及双上／双下，并按种子簇 bootstrap 95% 区间。只有两头均未退步、至少一头均值为正且两头积分差区间下界均不小于零，才允许启用；否则保留现网页行为，记录负结果与候选。此门槛是预先登记的部署检验，不是整场或全局最强证明。浏览器、合法性、信息边界及房间流程验证也须通过。

完整权重不进 Git，公开时使用不可变 GitHub Release 和 SHA。到点若融合程序未准备或验证失败，运行明确标为等待／失败，不能冒充上线。

## 截止后处理与恢复

运行协议固定 `finalizeRoot`，到点由采样器调用该专用检出的 `ai/publishing/finalize-tribute.mjs`。该检出须保持干净；融合器安全同步 main，重新加载同步后的程序，按协议指纹定位原冻结采样源码，再开展留出。评测逐局落盘，可以从完整局恢复；指纹不匹配则拒绝复用。

专项接入代码先合入但默认关闭；只有正式门槛通过后才批准这次冻结的两个底座 SHA。之后新冠军、新 GuanZero 默认继续原贡还，必须另测才能扩大批准范围。检查失败或发布竞争未能安全合并时，在运行目录保留 `fusion-error.json`，面板显示失败；不会强推或覆盖其他机器的 Release。可手工在专用干净检出重跑上述融合器，但不要重启采样或延长截止。

本次 Windows 交流电自动睡眠为三小时，另用 `awake_until.py --run=<运行目录> --pid=<该采样器 PID>` 申请 `ES_SYSTEM_REQUIRED`，不改电源计划且允许屏幕熄灭。请求与原进程句柄绑定，采样／融合进程退出即释放，最多到截止后一小时（只供验证发布，不增加训练）。系统 API 已实际接受请求；管理级 `powercfg /requests` 需提权，未将该查询写成已验证。手动睡眠／关机仍可中断运行，已落盘数据不会因此删除。
